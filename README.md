Dompet Keluarga — a household budget site for the Gunawan family in Bekasi: a dashboard with the month's money at a glance, a full transaction ledger you can add to and search, a budget per category you can edit in place, savings goals you can top up, and a six-month report with charts and a CSV export. Everything runs from static files with no network request, on desktop and on a phone, and every figure is real data that stays in the browser.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — the dashboard, transactions, budget, goals and report pages are all linked from the top navigation.
